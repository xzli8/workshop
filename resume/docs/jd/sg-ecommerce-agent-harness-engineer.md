## 岗位职责
1. 架构与框架设计：设计 Agent 系统的模块分层、接口和扩展机制，处理通用能力与产品需求之间的关系，支持多模型、多工具与不同运行环境。
2. 核心执行机制：设计和实现 Agent Loop、任务生命周期、状态持久化、后台执行、取消与中断恢复，保障长时间任务的可靠运行。
3. 工具与扩展系统：建设工具发现、动态加载、并发执行与权限控制能力，支持 MCP 接入、Skills 和插件管理。
4. 上下文与记忆：建设上下文组织、预算管理、压缩、历史回读及跨会话记忆能力，兼顾任务效果、成本与可恢复性。
5. Multi-Agent 协作：设计任务委派、消息通信、上下文共享与子任务生命周期，明确协作过程中的权限和资源边界。
6. 模型与执行环境接入：建设多模型适配、公共 API／SDK、审批机制，以及本地和远程沙箱等执行环境的接入能力。
7. 研究与工程验证：深入研究成熟 Agent 系统，通过设计评审、原型实验、故障测试与性能分析，验证技术选择，改善任务效果、可靠性、延迟和成本。
8. 评测与训练支撑：完善执行轨迹、诊断和回归验证能力，与算法团队协作，支持评测、Rollout 与训练数据链路。
