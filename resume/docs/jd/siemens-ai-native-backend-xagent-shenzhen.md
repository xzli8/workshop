# 西门子 — AI Native 后端工程师（企业级 AI Agent 开发平台 XAgent）

来源：Siemens 官网（https://jobs.siemens.com/en_US/externaljobs/JobDetail/526058），深圳。抓取日期 2026-11-01（搜索索引显示发布于 2026-10-16）。与 siemens-xagent-fde.md 同属 XAgent 平台，本岗是平台后端研发而非客户现场交付。

## 岗位职责
1. AI Agent 核心后端能力开发
- 参与 XAgent 企业级 AI Agent 开发平台的核心后端研发，将 AI Native 架构设计转化为可运行、可测试、可部署的工程能力。
- 开发 Agent Runtime 相关模块：任务执行、状态管理、执行步骤编排、异步任务处理、暂停恢复、超时控制及异常处理。
- 开发统一模型接入与调用服务：多模型适配、模型路由、调用参数管理、限流、重试、Fallback 及调用记录。
- 开发 Agent 执行上下文、会话状态、记忆存储和知识检索等后端能力。
- 参与 Workflow、单 Agent 及多 Agent 协作功能开发，确保执行过程可追踪、异常可定位、结果可验证。
- 基于底层模型与 Agent 引擎能力，设计并落地上层 AI 应用，面向企业业务场景完成应用封装、业务逻辑编排与场景化交付。
2. Skill / Tool 执行与生态接入
- 开发 Skill/Tool 注册、发现、配置、调用、版本管理及执行结果处理等核心模块。
- 支持 MCP 等工具接入方式，实现第三方 API、企业业务系统及工业软件能力的标准化封装与调用。
- 负责工具调用参数校验、权限校验、超时处理、异常恢复及执行结果结构化。
- 配合设计工具执行隔离、凭证管理、访问控制和审计机制。
- 支持生态伙伴开发的 Agent、Skill 和工具接入平台，解决接口兼容、执行稳定性及版本升级问题。
3. AI 工程化与质量保障
- 建立模型调用、Agent 执行和工具调用的日志、Tracing、指标采集及异常告警能力。
- 参与构建 Agent 评测与回归测试机制，验证任务完成情况、工具调用准确率、输出质量及异常处理能力。
- 针对生产环境中的幻觉、工具调用失败、上下文过长、模型超时等问题进行分析和优化。
- 优化 Prompt、上下文组装、缓存、并发调用和异步处理策略，降低推理成本与响应延迟。
- 编写单元测试、集成测试及自动化测试用例。
4. 企业级平台集成与工程交付
- 与云平台 Backend 团队协作，集成统一身份认证、租户管理、权限体系、数据库、消息队列和计费服务。
- 配合实现 Token 使用量及 Agent 执行任务的计量数据采集，支持商业计费与成本分析。
- 参与 Docker、Kubernetes 环境下的服务部署、性能测试、问题排查及生产运维。
- 遵循代码规范、分支管理、Code Review、CI/CD 和发布流程。
- 将平台架构设计和实际业务场景转化为可交付的软件功能。

## 任职要求
必备条件
- 计算机科学、软件工程、人工智能或相关专业本科及以上学历。
- 具备运用 AI 底层能力构建上层业务应用的实践经验，能基于 Agent/Workflow 能力完成场景化应用设计与落地。
- 3 年及以上后端开发经验，有实际 LLM 应用或 AI Agent 开发经验者优先。
- 精通 Python 或 Go 至少一种，具备良好的代码设计、数据结构、算法和问题排查能力。
- 熟悉 REST API、异步编程、数据库设计、缓存、消息队列及常见后端架构。
- 理解 LLM 基本工作机制，具备模型 API 集成、Prompt、RAG、Tool Calling 或 Agent Workflow 的实际开发经验。
- 具备分布式系统和并发编程基础，能处理超时、重试、幂等性、任务状态和异常恢复。
- 熟悉 Git、Linux、Docker 及研发协作流程，具备单元测试、集成测试和代码审查意识。
- 工作地点：深圳。

加分项
- LangGraph、LangChain 或其他 Agent Framework 实际开发经验。
- 熟悉 MCP Server / Client、工具注册发现、Function Calling 或多 Agent 协作。
- Agent Runtime、长任务执行、状态持久化、Checkpoint、任务恢复或工作流引擎开发经验。
- 熟悉向量数据库、Embedding、Rerank、知识库检索和上下文工程。
- LLM Gateway、模型路由、Token 计量、推理服务或 AI 成本优化经验。
- 熟悉 Kubernetes、Prometheus 等云原生部署和可观测性技术。
- 企业级 SaaS、多租户平台、开发者平台或工业软件集成经验。

核心能力：扎实的后端工程能力；AI 工程实践能力（封装为稳定可复用服务，而非 Demo）；AI 上层应用构建能力；可靠性设计（AI 执行与传统服务在状态管理、错误恢复、结果验证上的差异）；性能与成本意识；团队协作。
