# Veeva — 首席软件工程师（AI 应用方向）/ Principal Software Engineer, AI Application

来源：BOSS 直聘，北京·朝阳区·亮马桥，5-10 年，本科，联系人 袁清云（Veeva · 招聘经理）。抓取日期 2026-09-20。
标签：Java / Go / 分布式技术 / 容器技术 / Python
声明：研发岗位，不是管理岗位，面试有现场编码环节。

Veeva Systems 是 industry cloud 先驱，生命科学 SaaS，上一财年营收超 20 亿美元，2021 年成为 public benefit corporation。

## 岗位职责
作为 AI Application 方向的 Principal Software Engineer，负责将大模型能力应用到 Veeva 核心产品和业务流程中，设计并交付稳定、可扩展、可观测的企业级 AI 应用。不是算法研究或模型训练岗位，是面向真实业务场景的 AI 应用工程岗位。

- 负责 AI 应用在企业级 SaaS 产品中的架构设计和关键模块开发，包括 RAG、Agent、Workflow、Prompt Orchestration、Tool Calling 等。
- 设计和优化从业务数据、权限控制、上下文构建到模型调用、结果返回的完整链路。
- 将 AI 能力与 CRM 等核心业务系统集成，确保功能在真实生产环境中稳定、安全、可维护。
- 建设 AI 应用所需的评测、监控和反馈机制，持续提升结果质量、稳定性和可解释性。
- 优化大模型调用的延迟、成本、吞吐和容错能力。
- 处理企业级场景下的数据安全、租户隔离、权限过滤、审计追踪和合规要求。
- 与产品、设计、后端、前端、QA、SRE 及海外团队协作，将业务需求转化为可落地的 AI 产品能力。
- 在关键技术方向上保持 hands-on，参与核心代码开发、技术方案评审和复杂问题排查。

## 任职要求
- 8 年以上软件工程经验，有复杂业务系统、企业级 SaaS、CRM、搜索推荐、知识管理或数据密集型系统经验。
- 有 AI / LLM 应用落地经验，熟悉 RAG、向量检索、Embedding、Prompt Engineering、Agent、Function Calling / Tool Calling 等常见架构模式。
- 理解大模型应用在生产环境中的关键问题，包括准确性、幻觉、权限边界、上下文管理、评测、延迟、成本、稳定性和可观测性。
- 具备扎实的后端工程能力，熟悉 Python，或精通 Java / Go / C++ 等后端语言并愿意深入使用 Python 技术栈。
- 熟悉分布式系统、API 设计、异步任务、消息队列、缓存、关系型数据库和 NoSQL 数据库。
- 有云上系统开发经验，熟悉 AWS、Docker、Kubernetes、CI/CD 和常见监控体系。
- 能够独立推动复杂技术方向，从问题定义、方案设计、工程落地到持续迭代。
- 具备良好的产品意识和业务理解能力，能在技术可行性、用户体验、成本和风险之间做判断。
- 计算机、软件工程或相关专业，本科及以上学历。

## 岗位特点
- 面向 AI 应用落地的 Principal IC 岗位，需要深入业务、亲自写代码，并对关键技术方案和工程质量负责。
- 不期待训练基础大模型，但希望真正理解如何把大模型能力可靠地接入企业级 SaaS 产品中，包括数据、权限、评测、监控、成本和安全等问题。
- 适合既有扎实软件工程能力，又愿意在真实业务场景中推动 AI 产品化的人。
