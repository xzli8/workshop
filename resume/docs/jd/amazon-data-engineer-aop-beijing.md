# Amazon · Data Engineer - AI/ML Products, AOP（北京）

来源：https://www.amazon.jobs/en/jobs/10572912/data-engineer-ai-ml-products-aop-analytics-operations-and-programs ，2026-11-11 抓取（工具只返回摘要，非逐字原文）。
招聘主体：Amazon（中国）控股有限公司；类别 Software Development；薪资未标。

## 团队
- AOP（Analytics Operations and Programs）为 Amazon ROW（北美/欧洲/日本以外）运营做分析应用、AI/ML 产品和研究模型
- 覆盖印度、澳大利亚、新加坡、中东北非、拉美
- 合作方：PM、数据科学家、应用科学家、BI 工程师

## 职责
- 设计、构建、维护可扩展的数据管道（供 AI/ML 模型开发与部署）
- 搭建维护数据与 AI/ML 方案的 CI/CD
- 建设管理数据仓库、数据湖（含治理与安全控制）
- 把业务和数据科学需求转成技术需求
- 跟进数据工程趋势，提出基础设施改进
- 参与代码评审，参与制定团队最佳实践

## 基本要求
- 数据建模、数据仓库、ETL 管道经验
- 3 年以上数据工程经验
- 至少熟练两门：Scala、Java、Python、C/C++、Go
- 了解 AWS 或同类云服务
- 版本控制与 CI/CD 经验

## 加分项
- 非关系型存储（对象存储、文档、KV、图、列族）
- 训练部署过大规模优化的 AI/ML 系统
- 数据分析经验
- 大数据技术经验

## 匹配（按 2026-11-01 版中文简历）
- 匹配 45，结论：不投
- 对得上
  - Java + Python；AWS（Lambda、SQS、EventBridge、S3、DynamoDB、CDK）；CI/CD
  - Vendor360 数据接入（78 个源归 5 类访问模式、去重清洗、不可变带版本产物池、隔离区、可重放）可讲成 ETL 与治理
  - 非关系型存储：DynamoDB、S3
- 缺
  - 无 DE 职位经历（要求 3 年以上数据工程）
  - 数仓建模（维度建模、星型模型、SCD）没做过，面试必考 SQL 与数仓设计
  - Spark、Glue、EMR、Redshift、Airflow 均无（推荐系统的 Kafka→ClickHouse/Flink 链路是别人做的）
  - 没训练部署过 ML 模型
- 注意
  - 方向从后端/Agent 转数仓管道，Agent 工程化经验用不上
  - 职级可能 L4–L5，相对现在的 SDE II 可能平级或降级
