## 职位介绍
我们正在寻找热爱技术、充满激情的各级软件工程师加入团队。您将作为团队的一员，参与构建一个高可扩展的技术平台，为特斯拉现有及未来的产品与服务提供强有力的支持与保障。

## 职位描述
- 设计并开发高质量、高可扩展、稳定可靠的 Web 应用和/或后端服务。
- 开发与后端服务对接的客户端应用。
- 开发后端 Web 服务。
- 与安全团队紧密协作，参与代码分析与设计评审。
- 编写单元测试，确保代码质量。
- 处理 Bug 报告并发布修复版本。
- 参与代码评审，提升团队整体代码质量。
- 积极参与敏捷开发流程。
- 始终保持创新思维，致力于通过技术手段解决客户痛点。

## 任职要求
必备条件
- 计算机科学或相关专业本科或硕士学历，或具备同等经验与能力证明。
- 具备 5 年以上使用 Java、C、C++、C# 或其他面向对象语言开发面向外部客户软件产品的经验。
- 熟悉 Java Spring Boot 框架者优先。
- 有基于 SQL 的应用开发经验，如 MySQL、MS SQL 或 Oracle。
- 熟悉 Linux 或类 Unix 系统的使用与开发环境。
- 具备 AI 开发经验。
- 具备开发高可扩展性应用（Web 应用或后端服务）的经验。

优先条件
- 注重细节，能够自行发现并修复 Bug，编写高效、高质量的代码。
- 热情积极，具备良好的问题解决能力和主人翁意识，能够独立负责问题并推动彻底解决。
- 乐于在遵循敏捷开发、代码评审和持续交付（CI/CD）的团队中工作。
