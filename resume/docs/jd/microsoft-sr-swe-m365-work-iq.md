# Microsoft — Sr. Software Engineer, M365 Work IQ

来源：Microsoft 官网（apply.careers.microsoft.com，pid 1970393557007892），China, Beijing（+2 more），团队：M365 Core Asia Pacific Copilot Extensibility Engineering。抓取日期 2026-11-01，发布约 1 个月前。

## Overview
Work IQ is Microsoft 365 Copilot's workplace intelligence layer, enabling AI agents and experiences to securely reason over enterprise data such as emails, meetings, documents, Teams messages, and people signals. Work IQ exposes this intelligence through agent-first interfaces including REST APIs, Agent-to-Agent (A2A) protocols, CLI tooling, and Model Context Protocol (MCP) servers, enabling developers to build intelligent, enterprise-aware agents and applications.

The team is looking for a Senior Software Engineer for Work IQ whose primary engineering focus is building the intelligence platform that connects AI agents to Microsoft 365 knowledge. You will own the design and development of Work IQ's REST and A2A APIs, MCP infrastructure, retrieval and orchestration services, and developer tooling. Your work will shape how agents access, reason over, and act on enterprise knowledge, helping establish Work IQ as the foundation for the next generation of Microsoft 365 Copilot and agent experiences.

## Responsibilities
- Take ownership of critical product and platform areas of the Work IQ API and related agentic components.
- Set a high technical and quality bar for agentic systems and developer-facing tooling.
- Design and ship performant, reliable terminal experiences that developers depend on for daily work.
- Use data, benchmarks, and direct user feedback to guide iteration and investment.
- Collaborate across org boundaries to enable other teams to build agentic products on top of a shared foundation.
- Influence architecture, technical direction, and engineering standards beyond your immediate team.
