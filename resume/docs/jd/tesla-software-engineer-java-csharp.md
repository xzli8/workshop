## THE ROLE
As an experienced Software Engineer, you'll take part in the design and development of software for the current and next generation of Tesla's After-Sales related systems. You'll be developing highly complex applications to streamline business operations and improve overall user experience. You will also help integrate AI capabilities into production systems in a reliable, maintainable, and scalable way. The ideal candidate is a self-starter with a strong desire to increase efficiencies and make an impact while contributing to a cross-functional team.

## RESPONSIBILITIES
- Work closely with a wide variety of stakeholders to analyze and break down large requirements into small, simple, workable deliverables.
- Work across multiple projects simultaneously.
- Design, implement, and deliver to production complete end-to-end fully functional solutions.
- Develop scalable backend solutions using Java/Spring Boot, C#/.NET Core, Python, MySQL/SQL Server, and other open stack frameworks.
- Design, build, and productionize AI systems end-to-end — including LLM/API integration, RAG pipelines, agent/workflow orchestration, data preparation, evaluation, observability, and cost/performance optimization — not limited to feature-level demos.
- Ensure highest technical quality of your deliverables and that they are cost-effective to maintain.
- Contribute clean, concise documentation to Tesla's knowledge base.
- Automate repetitive development tasks and bring efficiency to the team.
- Multi-task and manage multiple assignments in a fast-paced environment.
- Agile/SCRUM experience is a plus.

## REQUIREMENTS
- 5+ years in application development in an enterprise environment.
- Backend development using Java (Spring Boot) and C#/.NET Core; familiar with MySQL and/or Microsoft SQL Server.
- Hands-on experience with RESTful API design & implementation and microservices architecture.
- Hands-on experience on Python-related project development.
- Proven hands-on experience delivering AI projects into production (beyond prototypes/PoCs), covering architecture design, service integration, evaluation/testing, deployment, monitoring, and iterative improvement.
- Familiar with practical AI engineering stacks such as LLM APIs, RAG, vector search, orchestration frameworks, and production concerns including latency, cost control, safety/guardrails, and failure handling.
- Notable experience with database programming using Microsoft SQL Server or MySQL 8.0.
- Ability to write unit test cases and test before promoting to higher environments.
- Utmost importance to performance and scalability of web applications.
- Distributed source control (GitHub or Bitbucket).
- Education: BS/MS in Computer Science or equivalent degree.
- Containerized (Docker) application development is preferred.
