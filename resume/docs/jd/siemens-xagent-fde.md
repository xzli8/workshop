## 岗位定位
FDE 是连接 XAgent 平台 AI 能力与工业业务的核心桥梁角色：深入客户现场、理解业务痛点、用 AI Agent 解决实际问题的前线工程师，对项目最终成功负责。

## 岗位职责
1. AI Agent 场景落地与交付
   - 深入业务部门、工业企业及生态合作伙伴，识别真实业务痛点，转化为可落地的 AI Agent 解决方案
   - 基于平台 AI 能力，完成 Agent、Skill、工具调用、知识库、业务本体及业务工作流的设计、开发、集成和部署
   - 参与工业产品设计、供应链管理、设备运维、视觉质检、能源审计、机床代码生成、企业知识问答等场景
   - 负责从需求分析、技术验证、原型开发到生产部署、用户验收及持续优化的完整交付闭环
   - 针对复杂或非标准场景快速开发适配组件、接口及定制功能，推动 PoC 走向规模化
2. 企业系统与工业软件集成
   - 对接企业现有 IT/OT 系统、工业软件、业务 API、数据库及第三方服务，封装为 Agent 可调用的工具或 Skill
   - 解决现场部署、系统兼容、网络访问、数据质量及业务流程适配等问题
   - 配合完成企业级部署所需的安全、性能、稳定性和可运维性验证
3. 客户协作与技术问题闭环
   - 直接与客户、产品经理、架构师及合作伙伴沟通，将需求转化为技术实施方案
   - 负责交付中的问题定位、根因分析、方案实施及风险跟踪
   - 通过原型、演示和可运行成果展示业务价值，支持售前验证、客户试点及商业化推广
   - 将重复需求和通用能力沉淀为标准化组件、模板、工具或平台需求
4. 平台能力建设与持续改进
   - 将项目实践反馈至 XAgent 平台；沉淀可复用的 Agent 模板、Skill、连接器、行业方案及部署工具
   - 建立交付文档、测试用例、技术方案和最佳实践
   - 跟踪 AI Agent、LLM、MCP、RAG、Skill、本体等技术发展

## 任职要求
必备
- 计算机、软件工程、自动化、人工智能或相关专业本科及以上
- 3 年以上软件开发、系统集成或技术解决方案交付经验；有 AI 应用开发经验者优先
- 熟悉 LLM 应用开发，了解 Prompt Engineering、RAG、Tool Calling、Harness、Agent Workflow，能独立完成 Agent 原型及应用开发
- 具备系统集成能力，能对接第三方 API、数据库、企业应用或工业软件
- 熟悉 Git、Linux、Docker，具备日志分析、问题定位和测试能力
- 沟通协作、问题分析及快速学习能力强，能在需求不明确时推动闭环
- 能适应面向客户和业务现场的工作方式；工作地点深圳

优先
- 工业软件、工业自动化、智能制造、设备运维、质量检测或能源管理项目经验
- LangGraph、LangChain、Harness 或其他 Agent 框架实际应用经验
- 熟悉 MCP、Function Calling、A2A、向量数据库及知识库建设
- 前端能力（React、TypeScript），能独立完成端到端原型
- Kubernetes、云平台部署、企业级身份认证、权限治理或私有化部署经验
- 客户现场交付、技术咨询、解决方案工程师或 FDE 经验

核心能力：业务理解、快速交付、端到端解决问题、产品化意识、结果导向。
加分行业：自动化设备、电气机械/器材、计算机/通信/其他电子设备。
