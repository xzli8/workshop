# Microsoft — Software Engineer II, Core AI（Azure Intelligent Container Platform）

来源：Microsoft 官网（apply.careers.microsoft.com，pid 1970393557007337），China, Beijing。抓取日期 2026-11-01，发布约 22 天前。

## Overview
Build the platform that makes AI reliable, resilient, and effortless to operate at global scale: fault-tolerant, self-managing, self-healing, highly scalable systems across public and private datacenters, with AI, Big Data, cloud infrastructure, Docker, Kubernetes and distributed systems. Team: Azure Intelligent Container Platform within CoreAI. Azure AI Services enable customers to build intelligent applications that see, hear, speak, understand and interpret; the mission is to turn breakthrough AI technologies into production-ready, first-class Azure services with the reliability, scale, simplicity and performance customers need.

## Responsibilities
End-to-end ownership: work with leading technology providers and engineering teams to bring AI technologies to Azure — architecture, productization, platform engineering, deployment, performance, reliability, security and customer experience.
- Build for massive scale: highly available, scalable distributed systems across global public and private datacenters.
- Engineer for resilience: fault-tolerant, self-managing, self-healing platforms designed for operational excellence.
- Push cloud-native innovation: Docker, Kubernetes, open-source technologies and cloud platforms.
- Make AI production-ready: turn rapidly evolving AI technologies into reliable, secure, performant, easy-to-use Azure services.
- Own the full lifecycle: architecture and design through implementation, testing, deployment, monitoring and continuous improvement.
- Solve hard problems in distributed systems, performance, availability, scalability, security, privacy and user experience.

## Required Qualifications
- AI-native mindset: proficient in modern AI technologies and tools, hands-on use of generative AI, AI coding assistants/agents and AI/ML frameworks in day-to-day engineering.
- Strong engineering fundamentals and quality mindset; robust, maintainable, production-grade software.
- Education: BS/MS in Computer Science, Engineering, or a related technical field.
- Industry experience: 3–5+ years in software development, architecture, system design, OOD or product engineering.
- Programming: strong hands-on experience in one or more of C#, Python, or Go.
- Production engineering: Web APIs, performance/load testing, security and privacy; building reliable services for production.
- Ownership & collaboration in a fast-paced, global engineering environment.

## Nice to Have

- Docker, Kubernetes and containerized applications.
